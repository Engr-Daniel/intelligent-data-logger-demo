Reproduce the original M1–M6 run ⌄

From the project checkout, install its development requirements, then run the archived offline experiment and regression suite.

pip install -r requirements-dev.txt
python scripts/run_experiment.py
python -m pytest -q

The run writes a new timestamped folder under reports/runs/ with validation, M5/M6 scoring, eleven offline answers and provenance. The recorded run shown here is 20260921T055826825005Z. No API key is required for the offline path.
